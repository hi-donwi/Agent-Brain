Provider and routing control

Account credentials are sent to this Brain service and stored by Brain. They are never returned to Agent Control.

Create it on this Brain host with brain router management-credential, then transfer it from the owner-only file to this Brain-origin page. Never paste it into Agent Control. It is kept only in this page session.

          OPERATING SYSTEM

          Brain background service

          Service installation/removal is controlled by the Brain CLI because it changes launchd/systemd state and can stop this gateway. The console does not invoke OS service commands.

          brain service install brain service uninstall

          ROUTING

          Routing profiles

          Changing a profile creates a new revision. Update each affected project egress policy before relying on it.

            LOCAL KNOWLEDGE

            Registered RAG sources

            Only Brain-registered roots can be indexed or searched. Paths are kept in Brain's private config and are never sent by this page. Indexing and embeddings use the local Ollama backend only.

              Register a new root in a Brain terminal with brain knowledge source add --id docs --name "Project docs" --root /absolute/path --collection docs.

                SKILLS AND TOOLS

                Brain user skills

                This unscoped console lists only Brain-user skills. Project and configured skill sources remain private to their caller. Skill files are displayed as text and never executed here.

                Install a Brain-user skill

                Paste one SKILL.md. Brain validates the name/format and scans for secrets and unsafe instruction patterns. Existing skills are never overwritten.
